# 03. 7-세그먼트 디코더 이론

## 3.1 디코더(Decoder)란

**디코더** = 인코딩된 작은 입력(N비트)을 의미 있는 더 큰 출력(M비트)으로 푸는 조합 회로.

7-세그먼트 디코더는:
- **입력:** 4-bit BCD 또는 hex (0x0 ~ 0xF)
- **출력:** 7-bit (또는 dp 포함 8-bit) 세그먼트 패턴
- **회로 종류:** 순수 조합 회로 (clock 불필요) — 단지 case 문(또는 LUT) 한 덩어리

본 모듈에서는 표시할 문자가 `0~9` 숫자 외에도 `*` (마스킹), `-` (대시), ` ` (빈칸), `F` `A` `I` `L` (FAIL 표시) 까지 필요하므로 일반 BCD 디코더가 아니라 **「확장 코드 디코더」** 를 만듭니다.

---

## 3.2 본 모듈의 입력 코드 정의

`src/seg7_decoder.vhd` 의 entity 입력은 4-bit `digit_in` 입니다. 그 값에 대해 다음과 같이 약속합니다:

| `digit_in` | 표시 | 의미 |
|---|---|---|
| `0000` (0x0) | `0` | 숫자 0 |
| `0001` (0x1) | `1` | 숫자 1 |
| `0010` (0x2) | `2` | 숫자 2 |
| `0011` (0x3) | `3` | 숫자 3 |
| `0100` (0x4) | `4` | 숫자 4 |
| `0101` (0x5) | `5` | 숫자 5 |
| `0110` (0x6) | `6` | 숫자 6 |
| `0111` (0x7) | `7` | 숫자 7 |
| `1000` (0x8) | `8` | 숫자 8 |
| `1001` (0x9) | `9` | 숫자 9 |
| `1010` (0xA) | `*` | **마스킹** (a,b,c,d,e,f,g 전체 점등) |
| `1011` (0xB) | `-` | 대시 (g 만) |
| `1100` (0xC) | ` ` | 빈칸 (전체 OFF) |
| `1101` (0xD) | `F` | F (FAIL의 F) |
| `1110` (0xE) | `A` | A (FAIL의 A) |
| `1111` (0xF) | `L` | L 또는 I·L 등 (※ 본 모듈은 `L`로 매핑) |

> `*` 와 `8` 은 모두 a~g 전체 점등이라 형태상 같지만, **본 프로젝트의 마스킹 문맥은 "별표 의미"** 이므로 코드 의도를 살리기 위해 별도 인코딩 `1010` 을 둡니다. 이렇게 분리해두면, 추후 보드를 dp(.) 까지 켜서 `8.` 패턴으로 바꾸는 등의 변경도 깔끔하게 적용할 수 있습니다.

## 3.3 진리표 (Common Cathode, active-high)

세그먼트 비트 순서는 본 모듈에서 **MSB 부터 `a,b,c,d,e,f,g,dp`** 로 정의합니다 (즉 `fnd_seg(7)=a`, `fnd_seg(0)=dp`).

| 표시 | digit_in | a | b | c | d | e | f | g | dp | seg(8) |
|---|---|---|---|---|---|---|---|---|---|---|
| `0` | 0000 | 1 | 1 | 1 | 1 | 1 | 1 | 0 | 0 | `11111100` (0xFC) |
| `1` | 0001 | 0 | 1 | 1 | 0 | 0 | 0 | 0 | 0 | `01100000` (0x60) |
| `2` | 0010 | 1 | 1 | 0 | 1 | 1 | 0 | 1 | 0 | `11011010` (0xDA) |
| `3` | 0011 | 1 | 1 | 1 | 1 | 0 | 0 | 1 | 0 | `11110010` (0xF2) |
| `4` | 0100 | 0 | 1 | 1 | 0 | 0 | 1 | 1 | 0 | `01100110` (0x66) |
| `5` | 0101 | 1 | 0 | 1 | 1 | 0 | 1 | 1 | 0 | `10110110` (0xB6) |
| `6` | 0110 | 1 | 0 | 1 | 1 | 1 | 1 | 1 | 0 | `10111110` (0xBE) |
| `7` | 0111 | 1 | 1 | 1 | 0 | 0 | 0 | 0 | 0 | `11100000` (0xE0) |
| `8` | 1000 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 0 | `11111110` (0xFE) |
| `9` | 1001 | 1 | 1 | 1 | 1 | 0 | 1 | 1 | 0 | `11110110` (0xF6) |
| `*` | 1010 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 0 | `11111110` (0xFE) |
| `-` | 1011 | 0 | 0 | 0 | 0 | 0 | 0 | 1 | 0 | `00000010` (0x02) |
| ` ` | 1100 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | `00000000` (0x00) |
| `F` | 1101 | 1 | 0 | 0 | 0 | 1 | 1 | 1 | 0 | `10001110` (0x8E) |
| `A` | 1110 | 1 | 1 | 1 | 0 | 1 | 1 | 1 | 0 | `11101110` (0xEE) |
| `L` | 1111 | 0 | 0 | 0 | 1 | 1 | 1 | 0 | 0 | `00011100` (0x1C) |

> ※ 보드의 실제 핀 매핑이 거꾸로(LSB=a, MSB=dp)라면 `quartus/fnd_driver.qsf` 에서 핀만 뒤집어 할당하면 됩니다. 이 진리표는 **모듈 내부 비트 순서** 의 약속입니다.

## 3.4 VHDL 구현 방식의 선택

### 방식 A — `with...select`
```vhdl
with digit_in select
    seg_out <= "11111100" when "0000",  -- 0
               "01100000" when "0001",  -- 1
               ...
               "00000000" when others;
```
장점: 매우 명료. **합성기가 LUT 한 덩어리** 로 변환.

### 방식 B — `case` 문 안에 process
```vhdl
process(digit_in)
begin
    case digit_in is
        when "0000" => seg_out <= "11111100";
        ...
        when others => seg_out <= "00000000";
    end case;
end process;
```
장점: 분기마다 주석 달기 좋음. 조건 추가 (예: `enable` 신호) 도 용이.

### 방식 C — LUT ROM
별도 패키지에 `constant lut : t_lut := (...)` 을 두고 `seg_out <= lut(to_integer(unsigned(digit_in)));`
장점: 재사용성 ↑. 단점: 본 프로젝트엔 과한 일반화.

**본 모듈은 가독성과 합성 결과(LUT 1개) 가 가장 명확한 방식 A** 를 채택합니다.

## 3.5 디코더가 전체 프로젝트에서 차지하는 역할

```
[비밀번호 모듈(정용성)]                    [본 모듈]
                                          ┌─────────────────────────┐
digit_data(16) ─────┐                     │  digit_scanner          │
  = [d3,d2,d1,d0]   │                     │  자리 카운터 (0~3)      │
  각 4-bit BCD      │                     └────────┬────────────────┘
                    │                              │ digit_sel(2)
                    │                              ▼
                    ▼                     ┌─────────────────────────┐
              ┌──── MUX ────┐             │ 4:1 MUX (자리 선택)     │
              │ 4자리 중 1개│ ◀───────────│                         │
              │ 4-bit 출력  │             └─────────────────────────┘
              └──────┬──────┘                          
                     ▼                                
              ┌──────────────────────────┐            
              │  ★ seg7_decoder ★       │  ← 본 문서의 모듈
              │  4-bit → 8-bit 변환      │
              └──────┬───────────────────┘
                     ▼
              fnd_seg(7..0) ──→ [보드 FND]
```

**디코더는 모듈의 마지막 단**(보드 핀 직전)에 위치하며, **현재 자리에 표시할 4-bit 코드 1개** 만 받아 8-bit 패턴으로 펼쳐줍니다.
4자리분의 디코더가 따로 있는 것이 아니라, **디코더 1개를 시분할로 공유** 하는 구조 (LUT 수 절약).

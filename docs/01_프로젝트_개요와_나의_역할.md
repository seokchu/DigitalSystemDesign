# 01. 프로젝트 개요와 나의 역할

## 1.1 팀 프로젝트 개요

### 주제
**FPGA 기반 디지털 도어락(Digital Door-Lock) 설계 및 구현**

사용자가 키패드로 비밀번호를 입력하면, FPGA 내부의 FSM(Finite State Machine, 유한상태기계)이 그 입력을 받아 저장된 비밀번호와 비교한 뒤,
- 일치 시 잠금 해제 (LCD/LED 표시 + 일정 시간 후 자동 잠금)
- 불일치 시 시도 횟수 증가 (3회 연속 실패 시 경보 모드)
- 별도 키 조합으로 비밀번호 변경 모드 진입

이러한 일련의 동작을 **순수 디지털 회로(VHDL)** 로 구현하는 프로젝트입니다.

### 사용 보드
- **HBE-Combo II-SE** (한백전자)
- 칩: ALTERA Cyclone II **EP2C8Q208C8**
- 내장 주변장치: 16개 푸시버튼, 8 DIP 스위치, 16 LED, 1-Digit FND, 4-Digit FND, 16×2 Character LCD, Piezo Buzzer, PS/2 키보드 포트, UART
- 클럭: **1MHz / 1kHz / 1Hz** (보드 내장 분주 옵션) — 본 모듈은 1MHz를 기준으로 동작

### 사용 툴
- HDL: **VHDL**
- 합성/배치배선: **Intel Quartus Prime**
- 시뮬레이션: **ModelSim-Intel FPGA Edition**

### 팀 구성 및 역할 분담

| 팀원 | 역할 | 산출물 |
|---|---|---|
| **이서영** (A) | FSM 제어 구조 + TOP MODULE 통합 | top.vhd, 신호 인터페이스 정의 |
| **손동한** (C) | 입력 처리 (디바운싱·키 인코딩·4자리 버퍼) | 입력 처리 VHDL |
| **정용성** (D) | 비밀번호 비교·변경·자동 잠금 타이머 | 비밀번호 FSM, 카운터 |
| **권우현** (??) | LCD 초기화·드라이버·상태별 메시지 | LCD VHDL |
| **★ 장현석 (E)** | **★ FND 출력 모듈 전체** | **★ FND 소스코드·테스트벤치** |
| **최미소** (F) | LED 점멸·Piezo 톤 생성·경보 | Piezo·LED VHDL |

## 1.2 시스템 블록도

```
[입력]                  [FSM 제어]              [출력]
─────────              ──────────              ───────────
Button SW ─┐                                ┌─→ LCD (권우현)
DIP SW ────┼─→ 입력처리(손동한)─→ FSM ──→ ─┼─→ ★ FND (장현석) ★
PS/2 KBD ──┘             ↑      (이서영)    ├─→ LED (최미소)
                         │                  └─→ Piezo (최미소)
                         ↓
                  비교/저장/타이머
                       (정용성)
```

**FND 모듈은 사용자의 가장 직접적인 시각 피드백 채널** 입니다. 비밀번호를 몇 자리 입력했는지(마스킹 + 자릿수), 시스템이 어떤 상태인지(대기/검증/경보)를 즉시 알려주는 역할을 합니다.

## 1.3 나의 담당 범위 (장현석 · FND 출력 모듈)

### A. 모듈 명세 (`장현석_역할별내용.pptx` 기준)

> HBE-Combo II-SE 보드의 4-Digit FND를 동작시키는 VHDL 모듈(`fnd_driver`) **단독 설계 및 검증** .
> 비밀번호 입력 진행 상황 · 시도 횟수 · 시스템 상태를 사용자에게 **시각적으로 피드백** 하는 출력 모듈.

### B. 구현해야 하는 핵심 기능 5가지

| # | 기능 | 설명 |
|---|---|---|
| ① | **7-세그먼트 디코더** | 4-bit BCD(0~9) → 7세그먼트 패턴(a~g+dp) 변환. Common Cathode 이므로 세그먼트 active-high. |
| ② | **시분할 멀티플렉싱** | 1MHz 클럭을 분주, 자리 선택 카운터(0→3 순환)로 4자리를 1ms씩 점등 (≈250Hz refresh) |
| ③ | **비밀번호 마스킹 표시** | `mask_enable=1` 일 때 입력된 자리만 `*` 패턴, 나머지는 빈칸. `input_count` 신호에 동기. |
| ④ | **FSM 상태별 표시 정책** | `fsm_state` 에 따라 화면 매핑(case문). IDLE/INPUT/CHECK/UNLOCK/ALARM/CHANGE 6상태. |
| ⑤ | **Reset 처리** | `reset_n='0'` 시 모든 카운터·출력을 즉시 안전 상태(빈 화면)로 클리어. |

### C. 산출물 (그대로 본 폴더에 매핑)

| 명세상 산출물 | 본 폴더에서의 위치 |
|---|---|
| `fnd_driver.vhd` (모듈 본체) | `src/fnd_driver.vhd` 외 4개 sub-block 모듈 |
| `fnd_driver_tb.vhd` (테스트벤치) | `testbench/tb_fnd_driver.vhd` 외 4개 단위 TB |
| `fnd_driver.qsf` (Quartus 핀배정) | `quartus/fnd_driver.qsf` |
| 시뮬레이션 파형 / 영상 | `sim/run_all.do` 로 재현 가능 |

## 1.4 본 모듈이 전체 시스템에서 차지하는 위치

```
            ┌─────────────────────────────────────────────────┐
            │              TOP MODULE  (이서영)               │
            │                                                 │
            │   ┌─────────────────────────────────────────┐   │
   key_in ──┼──→│   입력 처리 (손동한)                    │   │
            │   │   - 디바운싱  - 키 인코딩  - 4-bit 시프트│  │
            │   └────────────────┬────────────────────────┘   │
            │                    │ key_data(4), digit_done    │
            │                    ▼                            │
            │   ┌─────────────────────────────────────────┐   │
            │   │   비밀번호 비교/저장/타이머 (정용성)    │   │
            │   │   - 16-bit 비교  - fail_cnt  - 자동잠금 │   │
            │   └─┬───────────────┬────────────────────┬──┘   │
            │     │ fsm_state(3)  │ digit_data(16)     │      │
            │     │ mask_en       │ input_count(3)     │      │
            │     ▼               ▼                    ▼      │
            │   ┌──────────┐  ┌────────────────┐  ┌────────┐  │
            │   │ LCD      │  │ ★FND (장현석)★ │  │ LED·   │  │
            │   │ (권우현) │  │ ★    본 모듈   │  │ Piezo  │  │
            │   └──────────┘  └────────────────┘  └────────┘  │
            └─────────────────────────────────────────────────┘
                                  │
                                  ▼  fnd_seg(8), fnd_com(4)
                          [HBE-Combo II-SE 4-Digit FND]
```

- **상위 (Top FSM·이서영)** 로부터 `fsm_state` · `mask_enable` 신호를 받음
- **이웃 (입력처리·손동한)** 으로부터 `input_count` 받음
- **이웃 (비밀번호·정용성)** 으로부터 `digit_data(16-bit BCD)` 받음
- **하위 (보드 핀)** 로 `fnd_seg(8)` · `fnd_com(4)` 출력

내가 만드는 모듈은 위 신호들을 받아 **「사용자가 지금 무엇을 하고 있고, 시스템이 어떤 상태인지」** 를 사람이 알아볼 수 있는 빛 패턴으로 변환해주는 **번역기** 입니다.

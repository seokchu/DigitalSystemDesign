# Quartus 핀 배치 가이드 (HBE-Combo II-SE)

## 1. 보드 칩 사양

| 항목 | 값 |
|---|---|
| Family | Cyclone II |
| Device | **EP2C8Q208C8** |
| Package | PQFP 208 |
| User I/O | 138 |

## 2. 본 모듈이 사용하는 핀 목록

| 신호 | 방향 | 폭 | 본 모듈에서의 역할 | 보드 위치 (예시) |
|---|---|---|---|---|
| `clk` | in | 1 | 1MHz 시스템 클럭 | 클럭 선택 점퍼 (1MHz 위치) → FPGA 클럭 입력 핀 |
| `reset_n` | in | 1 | 비동기 리셋 (active-low) | 푸시버튼 SW (active-low 결선) |
| `fnd_seg[7:0]` | out | 8 | a,b,c,d,e,f,g,dp (active-high) | 4-Digit FND 세그먼트 라인 |
| `fnd_com[3:0]` | out | 4 | COM1~4 (active-low) | 4-Digit FND COM 라인 |

## 3. 핀 번호 확인 절차

1. **보드 매뉴얼 (HBE-Combo II-SE 사용자 설명서) 펼치기**
2. **"4-Digit FND" 섹션** 에서 a~g, dp 가 각각 어떤 FPGA 핀에 연결되어 있는지 표 확인
3. **"COM1~COM4"** 핀 번호 확인
4. **"Clock"** 섹션에서 1MHz 가 어느 핀에 들어오는지 확인 (점퍼 설정도 같이 확인 — 일부 보드는 점퍼로 1MHz/1kHz/1Hz 를 선택)
5. **"Push Button SW"** 섹션에서 RESET 으로 쓸 버튼 핀 확인

`quartus/fnd_driver.qsf` 의 `set_location_assignment` 라인을 본인이 확인한 핀 번호로 수정 후 컴파일.

## 4. 비트 순서 매핑 (보드 vs 모듈 내부)

본 모듈은 다음 순서로 비트를 약속:
- `fnd_seg(7)=a`, `(6)=b`, `(5)=c`, `(4)=d`, `(3)=e`, `(2)=f`, `(1)=g`, `(0)=dp`
- `fnd_com(0)=COM1`, `(1)=COM2`, `(2)=COM3`, `(3)=COM4`

**보드가 다르면** 핀만 뒤집어 할당:
```tcl
# 예: 보드가 dp 를 최상위로 둔다면
set_location_assignment PIN_xx -to fnd_seg[0]  ;# dp → 최상위 핀
set_location_assignment PIN_yy -to fnd_seg[7]  ;# a  → 최하위 핀
```
모듈 내부 코드는 그대로 두면 됩니다.

## 5. unused pin 처리

Quartus 의 기본 unused pin 처리는 "As input tri-stated" 입니다.
보드에 의도치 않게 신호가 떠 있으면 글리치 우려가 있으므로,
Assignments → Device → Device & Pin Options → Unused Pins
에서 **"As output driving ground"** 또는 **"As input tri-stated with weak pull-up"** 으로 설정 권장.

## 6. 보드 다운로드 절차

1. USB Blaster 케이블을 보드 JTAG 포트에 연결
2. Quartus → Tools → Programmer
3. Hardware Setup → USB-Blaster 선택
4. Mode: JTAG, `.sof` 파일 추가
5. Start → Progress 100% 확인
6. 보드 클럭 점퍼가 1MHz 위치인지 재확인
7. RESET 버튼 한 번 누른 후 동작 확인

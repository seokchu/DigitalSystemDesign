# Quartus 컴파일 가이드

## 1. Quartus 프로젝트 새로 만들기 (단독 검증용)

1. Quartus Prime → File → New Project Wizard
2. **Working directory** : 본 `quartus/` 폴더 또는 상위에 새 폴더 생성
3. **Project name & top entity** : `fnd_driver` (반드시 동일)
4. **Add Files**
   - `../src/seg7_decoder.vhd`
   - `../src/clk_divider.vhd`
   - `../src/digit_scanner.vhd`
   - `../src/display_policy.vhd`
   - `../src/fnd_driver.vhd`
5. **Family & device** :
   - Family : Cyclone II
   - Device : **EP2C8Q208C8** (정확히 선택)
6. **EDA Tool Settings** : Simulation = ModelSim-Altera (또는 Questa-Intel) / VHDL
7. Finish

## 2. 핀 배정 가져오기

방법 A) `.qsf` 직접 편집
- 본 폴더의 `fnd_driver.qsf` 의 `set_location_assignment` 라인을 본인의 `.qsf` 에 복사
- 핀 번호는 **반드시** 보드 매뉴얼로 확인 후 수정

방법 B) Pin Planner GUI 사용
- Assignments → Pin Planner
- Node 별로 PIN_xx 와 IO Standard 직접 입력

## 3. 컴파일

- Processing → Start Compilation (Ctrl+L)
- 정상 시 결과 : 0 Errors, (warning 약간 OK)
- 자주 보는 경고와 의미:
  | Warning ID | 의미 | 무시 가능? |
  |---|---|---|
  | (10036) Verilog HDL or VHDL warning at xxx.vhd: object "xxx" assigned a value but never read | 미사용 신호 | OK (의도된 디버깅용 신호일 수 있음) |
  | (10492) used as default initial value for register | reset 초기화 코드 | OK |
  | (332060) Node : altera_reserved_tck, tms, tdi, tdo 사용 | JTAG 핀 | OK |
  | (15714) Some pins have incomplete I/O assignments | 임의 핀이 미할당 | unused pin 옵션 설정으로 해결 |

## 4. 다운로드 (Programmer)

1. Tools → Programmer
2. Hardware Setup → USB-Blaster
3. Mode : JTAG
4. Add File → `output_files/fnd_driver.sof`
5. Program/Configure 체크
6. Start

## 5. 단독 검증 시나리오 (보드 위에서)

DIP 스위치/푸시버튼을 핀 할당해두었다면:

| 동작 | 입력 | 기대 결과 |
|---|---|---|
| reset 누름 | reset_n = 0 | FND 안전 상태 (모든 자리 OFF) |
| reset 해제 + fsm_state="000" | IDLE | `----` 표시 |
| fsm_state="001", input_count="000~100" 점진 변경 | INPUT 마스킹 늘어남 | `____`→`*___`→...→`****` |
| fsm_state="010" | CHECK 깜빡임 | 5Hz 로 **** ↔ blank |
| fsm_state="011" | UNLOCK | 빈 화면 |
| fsm_state="100" | ALARM | `FAIL` 표시 |
| fsm_state="101" + input_count 변경 | CHANGE 마스킹 | INPUT 과 동일 동작 |
| mask_enable=0, digit_data=DIP | INPUT raw 표시 | 입력 숫자가 그대로 보임 |

## 6. 통합 후 변경 사항 (3주차)

- Top entity 를 `fnd_driver` → 이서영의 `top` 으로 교체
- Pin Planner 의 `fsm_state`, `mask_enable`, `input_count`, `digit_data` 핀 할당 제거 (Top 내부 결선이 됨)
- 보드 핀 (clk, reset_n, fnd_seg, fnd_com, LCD, LED, Piezo, 버튼) 만 외부로 노출
- 컴파일 후 통합 검증 체크리스트 ([docs/07_통합과_인터페이스_명세.md](../docs/07_통합과_인터페이스_명세.md#74-통합-검증-체크리스트-3주차)) 항목 확인

## 7. 합성 결과 확인 (RTL & Technology Viewer)

- Tools → Netlist Viewers → RTL Viewer
  - 본 모듈의 4개 sub-block 이 인스턴스로 명확히 보여야 함 (이름 : U_DIV, U_SCAN, U_POL, U_DEC)
- Tools → Netlist Viewers → Technology Map Viewer
  - 디코더가 LUT 8개 (a~dp) 로 매핑되었는지 확인
- Compilation Report → Fitter → Resource Utilization by Entity
  - 본 모듈 전체 LE 사용량이 100 미만이어야 정상
